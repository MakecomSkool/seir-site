# SEIR. Непрерывность: каждый кадр, каждая склейка

Сайт — один непрерывный фильм. Этот документ фиксирует, ЧЕМ сделан каждый
переход, и проверяет, что кадры, механика и UX сходятся в одно целое.
Дополняет generation.md (промпты) и build.md (механика). При конфликте
промптов главнее generation.md, при конфликте механики — этот файл.

## Три типа склеек

1. **Кадр-в-кадр (цепь).** Последний кадр ролика = первый кадр следующего.
   Механика: `axisHold [0,1]` + `scrubWindow [0,1]` — сцена непрозрачна весь
   пролёт, видео играет от края до края, шов приходится ровно на границу
   сегментов. Движение делает камера в футаже, не CSS.
2. **Фазовая карта.** Чёрный (перед «Якістю» — белый) кадр с моно-строкой.
   Это и есть склейка (film.md): предыдущий финал гаснет ПОД картой, из карты
   открывается следующий старт. Разрешает смену локации без моста.
   Моно-строка появляется с отставанием (label lag), когда чернота ≥55%.
3. **Диссолв автоплей-акта.** Внутри актов III/IV сцены — отдельные портреты:
   уход в тёмный фон (III) или в белую подложку --paper (IV) через крутизну
   осей rise/still. Цепи кадров не требуют.

Смысловая бесшовность швов-карт:
- «ФАЗА 01»: контурная Украина (небо) → нырок в облака. Чёрный = проход
  сквозь ночь. Прямой мост генеративно невозможен (двойное экспо, 2 дубля).
- «ФАЗА 02»: ночной двор → чёрный ангар. Чёрный = въезд в темноту ангара.
- «ФАЗА 03»: последний конус гаснет → рассвет. Чёрный = ночь перед рассветом.
- «ФАЗА 04»: рассветный воздух → белая лаборатория. Карта БЕЛАЯ — «включили
  свет», подложка --paper подхватывает.
- «ФАЗА 05»: белый акт → тёмный интерьер у окна ночью. Чёрная карта — шаг
  из операционной в ночь. F_EP0 обязан держать тёплую лампу в кадре, чтобы
  не терять связь со светлым актом.

## Правила кадров этапов 2–5 (дополнение к generation.md)

- Этап 2: F_II0 генерится независимо (карта прикрывает), но II0→II3 держат
  одну геометрию зала — это цепь типа 1 внутри проезда.
- Этап 3: кадры без цепи, но ЕДИНЫЙ час рассвета и высота — иначе диссолвы
  порвут атмосферу. Проверять четвёрку рядом до утверждения.
- Этап 4: единый белый стол/свет; хвост стиля светлый (generation.md).
- Этап 5, F_EP1: генерить БЕЗ контура (модель рисует границу без Крыма),
  контур впечатывается композитом — пайплайн готов: гомография по опорным
  городам + полигон ukraineGeo (Крым проверен). Скрипт — в истории сессии,
  переиспользовать. После этого рисованный оверлей снимается и с эпилога.

## UX/UI-инвентарь (что уже сходится, что ждёт)

Сходится (проверено в браузере):
- hold-окна цепи: сцены непрозрачны весь пролёт, швы попиксельные;
- подписи сцен живут внутри пролёта, гаснут до шва, на шве один заголовок;
- label lag перебивок — строка не просвечивает сквозь тексты;
- белая перебивка + подложка перед «Якістю», инверсия хрома плавная;
- PhaseBar по PHASES, CatTag по cats с прицельным скроллом к карточке;
- эпилог отдыхает на финальном кадре (низ страницы = пик), секции дальше;
- reduced-motion: вертикальная версия с постерами, без анимаций.

Ждёт этапов:
- CAT-карточки проезда (акт II, фронт по content/catalog.ts) — с этапом 2;
- flow-линии по проводам реальных кадров (I.1, III.2) — после этапов 2–3;
- огни/контур финальной орбиты — этап 5 (композитный кадр);
- мобильная типографика и 9:16-видео — build.md шаг 8 после всех этапов.

Ручки на случай правок ритма: scrollVh/scrubWindow/axisHold в film.ts,
DIVE_*/FADE_* в UkraineMap (эпилог), CARD_IN/CARD_HOLD в FilmStage.
